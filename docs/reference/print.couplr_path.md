# Print a design path

Shows how many pairs the whole sweep generated out of how many exist,
and then the point table: one row per value, with the matching it found
and what finding it cost.

## Usage

``` r
# S3 method for class 'couplr_path'
print(x, ...)
```

## Arguments

- x:

  A `couplr_path` from
  [`match_path()`](https://gillescolling.com/couplr/reference/match_path.md).

- ...:

  Ignored.

## Value

`x`, invisibly.
